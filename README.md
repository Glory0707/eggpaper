# 🥚 eggpaper


![reader](docs/screenshots/reader.png)

**eggpaper** 是一个本地优先的轻量科研文献阅读器。它不做"更多翻译"，做两件别家没做的事：

1. **术语一致的翻译**——一篇一份术语表，贯穿划词、段落、全文、总结、问答全部链路
2. **论证骨架 + 眉批**——从作者写作意图解析论文：哪句是核心主张、哪个实验只是对照、哪段是凑字数的样板、哪里有 AI 痕迹

文献、术语、批注全部留在本机；无账号、无订阅，LLM 用你自己的 key（DeepSeek / GLM / 本地 Ollama，任意 OpenAI 兼容端点）。

## 功能总览（全部已实现并实测）

### 读

- **翻译三模式**：`原文` / `译文`（整版中文，排版公式保留）/ `双语`（对开：左英右中成对滚动 · 交替：一页原文一页译文）
- **位置记忆**：刷新、重开、换篇，回到你离开的那一行
- **阅读器基本盘**：适应宽度 / 适应页面 / 实际大小 / 百分比微调；页码直达 + 上下页（`PageUp`/`PageDown`）；论文内查找（`Ctrl+F`，命中逐处高亮、逐个跳转）。**`Ctrl+滚轮`只缩论文**（缩完光标底下那个字留在原地），`Ctrl+±` 才是浏览器缩放；论文缩放不动顶栏右栏
- **读进去的那几下**（不加说明文案，只给动作）：视口中心换段时，纸下缘轻轻报一句这一段是什么（`¶8 · 标准流程`）并给「译这段 / 问这段」，自己会走；书桌右缘一根发丝显示阅读进度；打开一篇有眉批的论文时，划线与批注卡自己"画"进来一次
- **护眼底纹**：纯白（默认）/ 豆沙绿 / 浅青绿 / 米黄，设置里点一下立刻换。纸面用 multiply 洗色而不是整屏蒙版——底变绿，字仍然是黑的（正文对比度 16.9:1），清晰度一分不让
- **字号**：小 / 标准 / 大 / 特大，设置里点一下立刻换，**论文正文不动**。四档不是重新排一套字号，是给整套字号乘一个数（`--fs-scale`），档与档的比例永远不乱；右栏作为"读的地方"本来就比左栏大一档（正文 14.5px）

### 懂

- **问题**（右栏第一个页签）：读一篇论文该带着的问题——`①要解决什么、为什么 / ②怎么解决的 / ③还有什么没解决 / ④还能做什么 / ⑤换个学科怎么看`。**五问随首次析读一次备齐**（要点进对应段 + 模型作答，按篇缓存），换篇即换一套；还能做什么 / 换个学科两问的每条追问，一点就带进提问面板问出去。**综述自动换口径**：③变成「它把文献怎么组织的？」——按什么线索分类、各块什么关系、落到哪些开放问题
- **页边只有两样东西**：批注卡（眉批与查译，钉在它引的那句话旁）和引文划线。段落角色退到后台，支撑五问与眉批的生成
- **眉批**：句级人性化批注——妥协让步 / 凑字数 / 生硬别扭 / 多余重复 / 吹嘘过头 / **AI 痕迹** / 点睛之笔 / 有坑。像实验室师兄在你肩膀边上说话。引文**按句子逐行划线**（跨几行就是几个块，行内划多长就是多长），点引文直接跳到纸上那一句；模型把引文改写过一两个词时，退到能对上的最长前缀，划线只盖真实存在的字
- **划词即钉**：划词气泡一键把译文钉到页边，或直接就这段提问

### 问

- **对话式提问**（右栏「提问」，照 DeepSeek / 豆包网页版的样子做）：回答**逐字流式**吐出来，中途可「停止生成」（已经吐出来的半截留着）；每条消息悬停出「复制 / 重新生成 / 删除」；**一摊对话一个上下文**，可新建 / 切换 / 改名 / 删掉整摊，标题自动取第一个问题。答案里的 ¶ 号与末尾「依据」角标都可点回原文。旁批、证据行、五问的「问 ↗」一点就把问题带过来并直接问出去；**切页签不会打断正在生成的回答**（面板常驻），等第一个字的那几十秒会写「正在想…」而不是留一个空气泡。**上下文随聊随管**：本会话全部问答都在窗口里，删掉的那条立刻不在；超出预算时较早的轮次压成摘要（保留结论、数字、依据段号、术语译法与未解决的问题）而不是被截断。**跨文献一起问**：输入框按 `/` 唤起文库选择器，勾选别的论文进来——库大时模型先"侦察"挑最相关的 2~4 篇，回答里《某论文》¶3 指向那篇的段落
- **论文专属推荐问题**：析读完成后自动生成 4 个最值得追问的问题，口径是**读懂**（怎么做的、数字在什么条件下得的、能不能用到别的体系），审稿人式的挑刺归导师三问——两边不重复
- **导入即通读**：PDF 拖进来，骨架与简报在后台自动生成，打开即有；析读带**真实进度**（已完成 n/m 项），析读、眉批、全文翻译都能中途「**停止**」——已生成的部分保留，翻译已译好的页下次接着用
- **框选视觉问答**：`r` 进入框选模式（顶部常驻提示 + 退出按钮，Esc 随时退出），圈住公式/图表/表格直接问（讲解此图 / 讲公式 / 挖表格），答完钉在页边的正是你圈的那块地方；图表灯箱里也能「问这张图」（可左右翻图）。回答按 markdown 排版，长回答框内滚
- **导师三问**：组会/答辩最可能被问住的 3 个问题 + 过关提纲。只问**作者自己没承认的那一层**（作者认了的、眉批标了的在问题页③），提示词里写死了"不要复述已承认的薄弱点"；**综述换综述切口**（分类框架站不站得住、漏了哪条线、评判标准一以贯之吗）。每问配「**去回答 ↗**」——预填提纲直达提问面板，让模型帮你起草口头回答
- **方法卡**：把 Methods 整理成"目标/体系/条件/步骤/注意事项"的可复现 protocol；默认露目标/体系/条件 + 前三步，「展开全部」看余下步骤与注意事项；每条步骤句尾的 `[¶n]` **可点跳回原文**核对。**综述自动换成谱系卡**（定位/对象/范围/脉络/入门建议）——它把领域梳理成了什么样子、分几条线、各线的代表工作，适合谁先读哪条；不预设数据集基准，综述有什么写什么
- **本文缩写表**：自动抽取缩写首现展开，一键收进术语表
- **该实验回答**：每条关键证据标注它直接回答的问题，论证链从「是什么」升级为「为什么」
- **图表速览**：论文插图自动抽取成画廊，灯箱放大、一键跳回原文所在页
- **导出**：阅读笔记一键导出 Markdown（一眼卡 + 论证骨架 + **五问 + 方法卡/谱系卡** + 眉批查译 + 全部问答），旁边一枚「**复制 Markdown**」直接进剪贴板——贴进 Notion/Obsidian/组会文档；术语表导出 CSV（Anki 也能直接导这个）

### 沉淀

- **文库**：分类（Zotero 的 collection 语义——一篇可同时属于多类，点分类即筛选，条目可直接拖进去或点左侧的 `＋` 勾选）+ 标题搜索 + 三种排序（最近导入 / **最近阅读** / 标题）。每一行只有标题与**第一作者**（PDF 里认出来的，认不出就不显示）。批注、骨架、问答全部落在本机 SQLite，下次打开原样都在
- **术语本**：**一篇文献一份**——析读时由模型从这篇正文里发掘它自己的术语（自造的方法名/材料/关键指标，只留正文里真找得到的），缩写表同一次一起出；划词一键收进；译名在所有输出中强制一致。没有全库共用的词表，也不预置种子词（共用表里大半是别的论文的词，点「在文中找」必然查不到）；旧论文进术语页会自己补一次发掘，不用为此重新析读
- **页边即资产**：查译、段译、眉批、**你自己写的批注**都钉在页边（统一卡片、可展开、可移除；同段重钉自动更新，框选答疑按区域各自成条），跟随论文保存。长批注展开时下方批注整体下让——永远不叠、不裁、不窜出纸张。**页边宽度按需给**：有批注才占满 184px，关掉眉批图层一点都不留（论文当场宽出近 200px）
- **批注的三种笔触**：类型归成三档（值得读 / 要当心 / 可跳过），纸上就分三种笔法——值得读是马克笔、要当心是波浪线、可跳过只有一条点线。九种是"常用款"而不是"全部款"：模型遇到装不下的东西会自造一条（"参考态不一""排版错位"），档位决定它怎么被划、页边什么颜色。**颜色只有三档**，因为读者一眼能分清的也就三档。引文按句子落行、精确到字符，跨空格的断口会自己接上；卡片里默认两行预览，点「全句」摊开整句
- **右栏四分工**：问题（五问；眉批只留一个生成入口，内容在纸面）· 速览（一眼卡 + 图表 + 方法卡/谱系卡 + 导师三问）· 提问 · 术语（本文缩写 + 术语表）；**宽度可拖**（双击复位，268–760px），面板可以整个收起。**同屏 2–4 篇对照读**时右栏改浮层——展开盖上来、收起还整屏给文献。分工按"谁负责哪一类信息"划死：一眼卡只做三十秒定位，「为什么重要」在问题①、「依据在哪」在②、「作者承认了什么」在③，速览里只留一个 ↗ 指针
- **节日换装**：到日子蛋自己换上——春节整印换朱砂、元宵坐进汤圆碗、端午粽叶小舟、中秋末行变月饼、毕业季学士帽、万圣南瓜灯、圣诞红帽、元旦派对尖帽，读书日末行翻开成书，立冬到立春戴围巾……全部收在印章框内、不压三条字条；清明、国庆等庄重与国家的日子主动不换（农历换装表 2026–2030 已逐年核对）
- **论文日历**：哪天读了什么、哪天入了什么（点某天回看当天篇目，点篇目直接打开），统计行一键**导出本月 .md**——组会汇报"这个月读了哪些"直接要清单
- **引用格式**：顶栏标题旁的「引用」——识别一次首页的刊头页脚（作者/刊名/卷期页/DOI，预印本连页边水印的 arXiv 编号一起抄），之后九种格式全在本地排：**长条目**（GB/T 7714 / APA 7 / Nature 体）、**短引用**（作者+年、作者+期刊+年、正文括注——PPT 与图注用）、**导入**（BibTeX / RIS / DOI）。点整行即复制，顶部一行字段核对（没认出来的虚着显示 `—`），**认不出的字段一律留空，不替你想**——编出来的卷号页码比空着更害人
- **全文双语导出**：pdf2zh 引擎（bing/google/deepl/openai 可配），奇页原文偶页译文；**按批流水线**——
  四页一批、批内坏页拆单兜底、超时自动重试，坏页回退原文并如实标注，一页卡不住全文；
  中断续译不用重花钱。译完后按钮变「重新全文翻译」，译文打不开点一下就重译

## 为什么做

市面上要么是云端订阅的重方案（小绿鲸/ReadPaper），要么是只有翻译的开源引擎（pdf2zh），要么是贵且不可溯源的通用 PDF 问答（ChatPDF 类）。eggpaper 补的是：**本地轻量壳 + 术语全链一致 + 论证骨架**。骨架层对应 argumentative zoning / rhetorical roles 研究，句级眉批连学术原型都少见——这是产品的身份标识。

## 设计原则

1. **本地优先**：数据只在本地；唯一出网是用户自己配置的 LLM/翻译服务。
2. **无账号无订阅**：LLM 用自己的 key（任意 OpenAI 兼容端点），一篇成本毛钱级。
3. **术语贯穿**：每篇一份术语表，约束该篇所有 AI 输出。
4. **可溯源**：一切 AI 结论给依据（¶编号/矩形锚点），点击跳回原文。
5. **界面减法**：不放解释性小字，同一信息只出现一处。判据——删掉这行字，用户会损失什么？没损失就删。
6. **做减法**：每轮规划先问"哪些该砍"。

## 架构

```
浏览器 UI（Vue3 + pdf.js，Inter + JetBrains Mono 两声字体，Fraunces 只署 wordmark）
        │ localhost
FastAPI：解析(PyMuPDF) · OCR(RapidOCR，随包分发) · 骨架/眉批/总结/问答/对比/术语(LLM 适配器) ·
        翻译调度(pdf2zh subprocess) · SQLite
        │ 出网仅两类
LLM API（OpenAI 兼容） · pdf2zh 翻译服务（google/bing/deepl/…）
```

工程纪律：外部引擎一律 subprocess 不 import（AGPL 边界）；单篇长上下文直塞不引入向量库；LLM 输出归一化校验（键/枚举/范围），失败报错不静默；动效只动 opacity/transform，尊重 `prefers-reduced-motion`。

已知限制：pdf2zh 经典版（1.9.x）不支持 glossary 参数，全文翻译的术语锁定暂缺（划词/段落/总结/问答四条链已覆盖）。

## 打包成安装包 + 给用户推更新

作者在自己的机器上构建、发布，装了的人打开软件就收到提示，点一下就升级。
**升级只换程序，不动数据**：用户数据（配置、文库 PDF、SQLite、批注）在
`%LOCALAPPDATA%\eggpaper\data`，安装目录只放程序。

```bash
# 一次性：装打包工具
uv venv .build-venv --python 3.11
uv pip install --python .build-venv/Scripts/python.exe -r backend/requirements.txt pyinstaller pillow
winget install --id JRSoftware.InnoSetup

# 每次发布：改 VERSION（比如 0.2.0）→ 一条命令
python tools/build_installer.py --notes "这一版改了什么（会显示在用户的更新提示里）"

# 发布更新源（本机或局域网；也可以把 release/ 整个传到对象存储 / GitHub Releases）
python tools/serve_update.py
```

产物在 `release/`：`eggpaper-<版本>-setup.exe` + `latest.json`（版本、大小、sha256、说明）。
用户在「设置 → 更新源」填 `http://<你的IP>:8440`，之后每次打开软件会在 6 秒后安静地
问一次 `latest.json`：有新版就弹提示，点「下载并安装」→ 下载完校验 sha256 →
「立即重启并安装」会在后台静默装掉并重启软件。

安装包本身：

- `PrivilegesRequired=lowest`：默认装到 `%LOCALAPPDATA%\Programs\eggpaper`，**全程不弹 UAC**；
  想换盘（比如 `D:\eggpaper`）在向导的「选择安装位置」页改——那一页是开着的，改一次就记住了。
- **英文/中文**：向导是中文的（`[Messages]` 直接覆盖，不依赖第三方翻译文件），
  并且**只有一个语言**，所以不会有"选择安装语言"那一页。
- 向导哪些页：欢迎 → 选择安装位置 → 附加任务（桌面快捷方式）→ 准备安装 → 完成。
- 升级认的是固定的 `AppId`，并且回到**上次装的那个目录**——静默升级不会装出第二份（向导脚本里不能手写默认路径，否则会覆盖它记住的上次位置，踩过坑）。
- 卸载**不删用户数据**（数据在 `%LOCALAPPDATA%\eggpaper\data`，不在安装目录里）。

装完就有这些桌面该有的东西：

- **双击 PDF / 右键「用 eggpaper 打开」**：装完就注册好，**但不抢你的 .pdf 默认程序**——
  只加进「打开方式」列表和右键菜单（一个读论文的工具把 PDF 默认程序顶掉是冒犯，不是功能）。
  应用已经开着的时候双击，不会起第二个进程，界面自己切到那一篇。
- **托盘图标**（打包版默认开）：打开界面 / 在独立窗口打开 / 检查更新 / 退出。
  没有它的话，想关掉这个后台服务只能进设置里点或者去任务管理器。
- **独立窗口**：`eggpaper.exe --window`，或设置里点「在独立窗口打开」。没有地址栏、
  没有标签页，任务栏里就是 eggpaper 自己。实现是 **Edge/Chrome 的应用模式**——
  Windows 上 WebView2 的运行时提供者本来就是 Edge，同一个引擎，不必往安装包里塞
  WebView2 那几十兆；装了 `pywebview` 的话会自动优先用它。
- **图标**：16/24/32/48/64/128/256 七档分别绘制并嵌进 exe（`tools/make_icon.py`）。

两个先天的限制说清楚：

- 安装包**没有代码签名**，Windows 首次运行会提示「未知发布者」——点"仍要运行"即可。
  要消掉它得买一张代码签名证书，然后在 `installer/eggpaper.iss` 里填 `SignTool`。
- **全文翻译（pdf2zh）没打进包**（引擎 308MB，安装包要贴着更新渠道 100MB 的单文件上限）。
  第一次点「全文翻译」会**自动在后台下载安装**——更新源/镜像/官方直连自动换源、
  断点续传、sha256 校验，右下角一张小卡显示进度，装好自动接着翻译；
  设置 → 翻译引擎里也有手动安装（含从本地 zip 装，给完全离线的机器）。

**打包版的数据目录和源码运行是两处**：安装版默认读 `%LOCALAPPDATA%\eggpaper\data`，
源码运行读 `backend/data`；设置里可把数据目录迁到任意位置（如 D 盘），重启后自动搬迁。
数据目录里每篇文献一个文件夹：`papers/<论文id>/` 下是原件 paper.pdf、译文 mono.pdf、
双语缓存 dual.pdf 和页级中间产物 .pages/（删论文 = 删文件夹）；库索引在 `eggpaper.db`。

## 关于标记

![mark](docs/screenshots/mark.png)

一枚**印章**：椭圆环 + 环内几行字（末行短一截）。环是纸的边界，字是内容——印章正是批注本自己的语言；而椭圆环又刚好是蛋的轮廓，名字里的 egg 靠形状带出来，不靠画一只蛋。

几何**按目标像素算**（`backend/mark.py`）：每一档由「环内高度 ÷ (2n+1)」直接解出字条位置；三条字条是标识，放不下压薄字条也不减条。16 → 256px 都立得住——判据是**白缝**，不是"笔画够不够粗"。

改图标（换形状、查缓存、验任务栏）看 [docs/lesson.md](docs/lesson.md) 的图标一节：四条链路一个真源，标准动作与闸门都在那里。

默认永远是一副面孔；「节日换装」是到日子的临时装扮，收在印章框内、不压三条字条，过完日子自己脱下。至于「蛋仔派对」那个游戏：玩心只借它的**动作**（空态拖入时原地弹跳、析读完成时滚半圈），不借它的配色和形象——糖果色和 Q 萌吉祥物与「明亮的批注本」不是一套调性，而且那四个字是法院认过的未注册驰名商标，靠太近不划算。

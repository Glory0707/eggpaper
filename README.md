# 🥚 eggpaper


![reader](docs/screenshots/reader.png)

**eggpaper** 是一个本地优先的轻量科研文献阅读器。它不做"更多翻译"，做两件别家没做的事：

1. **术语一致的翻译**——一篇一份术语表，贯穿划词、段落、全文、总结、问答全部链路
2. **论证骨架 + 眉批**——从作者写作意图解析论文：哪句是核心主张、哪个实验只是对照、哪里有 AI 痕迹

文献、术语、批注全部留在本机；无账号、无订阅，LLM 用你自己的 key（DeepSeek / GLM / 本地 Ollama，任意 OpenAI 兼容端点）。

## 功能总览

### 读

- **翻译三模式**：`原文` / `译文`（整版中文，排版公式保留）/ `双语`（对开：左英右中成对滚动 · 交替：一页原文一页译文）
- **位置记忆**：刷新、重开、换篇，回到你离开的那一行
- **阅读器基本盘**：适宽 / 适页 / 实际大小 / 百分比微调；页码直达 + 上下页；`Ctrl+F` 论文内查找（命中逐处高亮、逐个跳转）。`Ctrl+滚轮`只缩论文（锚在光标底下那行），`Ctrl+±` 才是浏览器缩放
- **护眼底纹**：纯白（默认）/ 豆沙绿 / 浅青绿 / 米黄，点一下立刻换。纸面用 multiply 洗色——底变绿字仍是黑的
- **字号**：小 / 标准 / 大 / 特大，立刻生效，论文正文不动

### 懂

- **问题（七问）**：要解决什么、为什么 / 原理是什么 / 怎么解决的 / 结论有哪些 / 还有什么没解决 / 还能做什么 / 换个学科怎么看。随首次析读一次备齐（按篇缓存），换篇即换一套；综述自动换口径（②问领域共识、③问文献组织）
- **眉批**：句级批注——妥协让步 / 凑字数 / 生硬别扭 / 多余重复 / 吹嘘过头 / AI 痕迹 / 点睛之笔 / 有坑。引文按句子逐行划线，点引文跳到纸上那一句
- **划词即钉**：划词气泡一键把译文钉到页边，或直接就这段提问
- **页边只有两样东西**：批注卡（眉批与查译）和引文划线

### 问

- **对话式提问**：回答逐字流式，中途可停止（半截保留）；每条消息悬停出复制 / 重新生成 / 删除；多会话管理，标题自动取第一个问题；答案里的 ¶ 号可点回原文；超出预算的早期轮次压成摘要而不是截断。输入框按 `/` 唤起文库选择器，勾选别的论文一起问——库大时模型先侦察挑最相关的 2~4 篇；引用了别的论文时输入框旁多一枚「数据对比」直达对比表
- **推荐问题**：析读完成后自动生成 4 个最值得追问的问题（口径是读懂；审稿人式挑刺归导师三问）
- **导入即通读**：PDF 拖进来，骨架与简报后台自动生成；析读、眉批、全文翻译都能中途停止——已生成的部分保留，已译好的页续译接着用
- **框选视觉问答**：`r` 进入框选，圈住公式/图表/表格直接问，答完钉在你圈的位置；图表灯箱里也能「问这张图」
- **导师三问**：组会/答辩最可能被问住的 3 问 + 过关提纲（综述换综述切口）；每问配「去回答 ↗」预填进提问面板
- **方法卡**：Methods 整理成可复现 protocol（目标/体系/条件/步骤/注意），步骤句尾 `[¶n]` 可点跳回原文；综述自动换谱系卡（定位/对象/范围/脉络/入门）
- **一眼卡**：一句话 / 创新点 / 发现（最硬的数字结论）/ 关键词
- **本文缩写表**：自动抽取缩写首现展开，一键收进术语表
- **该实验回答**：每条关键证据标注它直接回答的问题
- **图表速览**：插图自动抽取成画廊，灯箱放大、跳回原文所在页
- **导出**：阅读笔记一键导出 Markdown（一眼卡 + 骨架 + 七问 + 方法卡/谱系卡 + 眉批查译 + 问答），或直接复制进剪贴板；术语表导出 CSV

### 沉淀

- **文库**：分类（一篇可属多类）+ 标题/全文搜索 + 四种排序（最近导入 / 最近阅读 / 发表时间 / 标题）。同一篇论文的另一版本导入时问一次：替换旧篇（问答、术语、分类跟迁）还是两篇都保留
- **术语本**：一篇一份——析读时从这篇正文里发掘（自造的方法名/材料/关键指标），划词一键收进，译名在所有输出中强制一致
- **页边即资产**：查译、段译、眉批、你自己写的批注都钉在页边，跟随论文保存；页边宽度按需给，没批注一点不占
- **批注三种笔触**：值得读（马克笔）/ 要当心（波浪线）/ 可跳过（点线），档位决定笔触，标签决定名字
- **右栏四分工**：问题 · 速览 · 提问 · 术语；宽度可拖（双击复位），可整栏收起；同屏 2–4 篇对照读时右栏改浮层
- **论文日历**：哪天读了什么、哪天入了什么；点某天的 ＋ 排计划待读；一键导出本月 .md
- **引用格式**：识别一次首页刊头页脚（作者/刊名/卷期页/DOI，预印本连 arXiv 水印一起抄），本地排九种格式：GB/T 7714 / APA 7 / Nature 体 / 短引用 / BibTeX / RIS / DOI。认不出的字段留空，不替你想。文库多选可一键导出引用表格 CSV
- **DOI / arXiv 可点**：悬停亮起，直达 doi.org / arxiv.org
- **全文双语导出**：pdf2zh_next 引擎（BabelDOC 内核；bing/google/deepl/openai 可配），八页一批流水线，批内坏页拆单兜底、中断续译；本篇术语表随全文翻译注入（LLM 类服务）

### 键盘流

`j/k` 段间步进 · `PageUp/PageDown` 翻页 · `Ctrl+F` 论文内查找 · `t` 译当前段并钉页边 · `s` 译划选 · `r` 框选问 AI · `c` 截图 · `1/2/3` 三模式 · `/` 提问 · `a` 析读 · `m` AI 眉批 · `x` 折叠右栏 · `g l` 文库 · `Alt+←` 返回原位 · `Esc` 收起所有浮层/退出框选 · `?` 快捷键卡

## 为什么做

市面上要么是云端订阅的重方案，要么是只有翻译的开源引擎，要么是贵且不可溯源的通用 PDF 问答。eggpaper 补的是：**本地轻量壳 + 术语全链一致 + 论证骨架**。

## 设计原则

1. **本地优先**：数据只在本地；唯一出网是用户自己配置的 LLM/翻译服务
2. **无账号无订阅**：LLM 用自己的 key，一篇成本毛钱级
3. **术语贯穿**：每篇一份术语表，约束该篇所有 AI 输出
4. **可溯源**：一切 AI 结论给依据（¶编号/矩形锚点），点击跳回原文
5. **界面减法**：不放解释性小字；删掉这行字用户没损失，就删

## 架构

```
浏览器 UI（Vue3 + pdf.js）
        │ localhost
FastAPI：解析(PyMuPDF) · OCR(RapidOCR) · 骨架/眉批/总结/问答/对比/术语(LLM 适配器) ·
        翻译调度(pdf2zh subprocess) · SQLite
        │ 出网仅两类
LLM API（OpenAI 兼容） · pdf2zh 翻译服务
```

工程纪律：外部引擎一律 subprocess 不 import（AGPL 边界）；单篇长上下文直塞不引入向量库；LLM 输出归一化校验，失败报错不静默；整文类 AI 调用共享逐字节相同的提示词前缀以命中服务端上下文缓存（输入费用约 1/50）。

已知限制：全文翻译的术语锁定只在 LLM 类服务生效——bing/google 不吃 prompt，物理上没法约束译法（划词/段落/总结/问答四条链不受此限）。

## 打包与更新

```bash
# 一次性：装打包工具
uv venv .build-venv --python 3.11
uv pip install --python .build-venv/Scripts/python.exe -r backend/requirements.txt pyinstaller pillow
winget install --id JRSoftware.InnoSetup

# 每次发布：改 VERSION → 一条命令
python tools/build_installer.py --notes "这一版改了什么（会显示在用户的更新提示里）"

# 发布更新源（本机或局域网；也可以把 release/ 传到对象存储 / GitHub Releases）
python tools/serve_update.py
```

产物在 `release/`：`eggpaper-<版本>-setup.exe` + `latest.json`。更新源内置为 Gitee 仓库的 raw 地址（自建源改 `config.yaml` 的 `update.feed_url`），打开软件会安静地检查一次：有新版弹提示 → 下载 → 校验 sha256 → 重启安装。

要点：

- `PrivilegesRequired=lowest`：装到 `%LOCALAPPDATA%\Programs\eggpaper`，不弹 UAC；升级认固定 `AppId`，回到上次安装目录，静默升级不会装出第二份；卸载不删用户数据
- 双击 PDF / 右键「用 eggpaper 打开」装完即注册，但不抢 `.pdf` 默认程序；应用开着时双击不会起第二个进程
- 托盘图标（打包版默认开）：打开界面 / 独立窗口 / 检查更新 / 退出
- 独立窗口是 Edge/Chrome 应用模式（`eggpaper.exe --window`）
- **没代码签名**：首次运行提示未知发布者，点"仍要运行"（正式发布前不买证书）
- **全文翻译引擎没打进包**（约 600MB）：第一次点「全文翻译」自动后台下载安装（多源换源、断点续传、sha256 校验），装好自动接着翻；设置 → 翻译引擎可手动装（含本地 zip，给离线机器）
- **数据目录**：全新安装默认在安装目录旁 `data\`（不可写才回退 `%LOCALAPPDATA%\eggpaper\data`，老安装原地继续），源码运行读 `backend/data`；升级只换程序不动数据。每篇文献一个文件夹（paper.pdf / mono.pdf / dual.pdf），库索引在 `eggpaper.db`；设置里可迁移
- **设置 → 备份**：导出全库 zip / 从备份恢复（重启后生效）——换电脑一份备份搬走全部数据

## 运行

```bash
# 后端（Python 3.10+）
pip install -r backend/requirements.txt
python backend/main.py                    # 127.0.0.1:8430

# 前端
cd frontend && npm install && npm run dev # http://localhost:5173
```

首次打开：设置 → 填任意 OpenAI 兼容 base_url + key + model → 测试连接。不填 key 也可用（演示模式，顶栏常驻徽标）。界面中英双语（设置里切）。应用内使用指南：设置 → 使用指南，或 [/guide](http://127.0.0.1:8430/guide)。

设计文档：[visual.md](docs/visual.md)（交互与视觉规范）· [lesson.md](docs/lesson.md)（踩坑、工作流与要求）。

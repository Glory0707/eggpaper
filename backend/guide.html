eggpaper 使用指南

若需使用完整功能，请先点击设置的教程配置模型。

阅读

  • 打开文献：PDF 拖进窗口任意位置即可导入（可一次拖入多篇）；也可以点「论文，启动！」或下方印章选择文件。装好 eggpaper 后，右键 PDF 可选用 eggpaper 打开。
  • 翻页与缩放：底部工具条翻页、输页码直达、适宽/适页；Ctrl + 滚轮自由缩放。
  • 查找：Ctrl + F 在论文内查找，命中高亮。
  • 原文链接：论文里的 DOI 与 arXiv 编号可点，直达 doi.org / arxiv.org。
  • 截图：工具条「截图」或按 c——拖拽框选一块区域，原图直接进剪贴板；设置里可开关是否保存到本地，文件在截图目录，可在设置打开。
  • 划词：选中文字弹出气泡——翻译 / 钉在页边 / 写批注 / 收进术语 / 提问。译文页的中文同样可以划选复制。
  • 回原位：Alt + ← 回到跳转前的位置。

顶栏

全文翻译：原文 · 译文 · 双语三种版面。点「全文翻译」开始（第一次自动下载翻译引擎，需等初始化）；服务默认 bing（免费），可在设置换。

析读：析读生成的内容在右栏；析读、眉批、全文翻译都能中途停止——已生成的部分保留，已翻译好的页可续译。

框选：框选公式/图表/表格直接提问（需模型支持视觉）。

引用：顶栏「引用」识别后生成各格式，点击复制（GB/T / APA / Nature / BibTeX / RIS / PPT 等）。

页边

  • 钉在页边：查/译/批注成为页边一张卡，卡片上 × 移除。
  • AI 眉批：右栏「问题」页点「AI 眉批」，模型通读全文后把值得当心/点睛/可疑的句子写在页边。设置里可以关闭。

右栏

  • 问题：预置七问，综述自动换口径；答案里的 ¶n 代表段落，点击跳到原文。
  • 速览：一眼卡、图表速览、方法卡（研究型）或谱系卡（综述）、导师三问，可导出 .md / 复制 Markdown；方法卡句尾 ¶n 跳回原文，导师三问配「去回答」起草口头回答。
  • 提问：可多会话、可停止/重生成/删除单条；输入框按 / 可勾选其他论文一起问（多篇文献时自动先挑最相关的几篇）。
  • 术语：本篇的缩写和术语表，划词可收进，也可主动收录；可导出 CSV。

左栏

  • 文库：统一管理文献，可按最近导入/最近阅读/发表时间/标题排序；搜索框搜标题，也搜全文。可多选进行同屏阅读（最多4篇）/数据对比/引用表格导出/分类/删除。导入与库里同一篇的另一版本时会问一次：替换旧篇（问答、术语、分类跟迁）还是两篇都保留。
  • 从 Zotero 导入：文库底部长按拖放区（需要 Zotero 7 在本机打开）勾选条目，导入PDF和相应信息。
  • 论文日历：左栏日历按钮（g c），哪天读了哪篇、哪天新增了哪篇；点某天的 ＋ 把文献列为当日待读，打开那篇自动移出待读；可导出本月 .md。
  • 目录：左侧栏目录按钮（g o），论文自带书签，点击跳页。

设置

  • 底纹 · 字号：论文正文不受字号影响。
  • English：切英文后翻译相关入口一并收起；已析读内容不受影响，之后析读生成英文。
  • 数据目录：本地存放个人数据，可迁移和打开查看，卸载更新重装不会删除个人数据。
  • 备份：导出全库 zip / 从备份恢复（恢复在重启后生效）。
  • 快捷键：论文界面按 ? 呼出快捷键卡。
  • 独立窗口：可在设置或电脑托盘右键打开独立窗口使用，软件可多开。
  • 演示模式：没配模型时顶栏常驻「演示模式」。

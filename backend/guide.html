eggpaper 使用指南

读

  • 打开文献：PDF 拖进窗口任意位置即可导入；也可以点「论文，启动！」或下方印章选择文件。装好 eggpaper 后，右键 PDF 可选用 eggpaper 打开。
  • 翻页与缩放：底部工具条翻页、输页码直达、适宽/适页；Ctrl + 滚轮自由缩放。
  • 查找：Ctrl + F 在论文内查找，命中高亮，逐个跳。
  • 翻译：原文 · 译文 · 双语三种版面。译文要先跑「全文翻译」；双语对开时左右两页同高对齐。
  • 目录：左侧栏目录按钮（g o），论文自带书签，点击跳页。
  • 回原位：Alt + ← 回到跳转前的位置。
  • 长任务：析读带真实进度（已完成 n/m 项）；析读、眉批、全文翻译都能点「停止」——已生成的部分保留，翻译已译好的页下次接着用。

页边

  • 划词：选中文字弹出气泡——翻译 / 钉在页边 / 写批注 / 收进术语 / 提问。译文页的中文同样可以划选复制。
  • 钉在页边：查译成为页边一张卡，卡片上 × 移除。
  • AI 眉批：右栏「问题」页点「AI 眉批」，模型通读全文后把值得当心/点睛/可疑的句子写在页边。设置里可以关闭。
  • 框选问图：框选公式/图表/表格直接问。

右栏

  • 问题：要解决什么、为什么 / 怎么解决的（综述问「它把文献怎么组织的」）/ 还有什么没解决 / 还能做什么 / 换个学科怎么看。答案里的 ¶n 代表段落，点击跳到原文。
  • 速览：总结、图表速览、方法卡（研究型）或谱系卡（综述）、导师三问、导出笔记 .md / 复制 Markdown。方法卡每条步骤句尾的 ¶n 可点跳回原文；导师三问每问配「去回答 ↗」，一键起草口头回答；一眼卡的关键词点一下就在文中查找。
  • 提问：对话式问答，可多会话、可停止/重生成/删除单条；输入框按 / 可勾选其他论文一起问（库大时自动先挑最相关的几篇）。
  • 术语：本篇的缩写和术语表，划词可收进；可导出 CSV。

其它

  • 引用：顶栏「引用」——GB/T / APA / Nature / BibTeX / RIS，点击复制。
  • 文库：分类、搜索、按最近阅读排序；文献删除时批注、问答一并清除。搜索框旁的列表图标进多选：勾几篇批量同屏阅读、数据对比（每格可点 ¶ 跳回原文）、归入分类、删除。
  • 从 Zotero 导入：文库底部长按拖放区（需要 Zotero 7+ 在本机开着）——勾选它库里的条目，PDF 连标题/作者/年份一起导进来。
  • 论文日历：左侧栏日历按钮（g c），哪天读了哪篇、哪天新增了哪篇；统计行可导出本月 .md。
  • 底纹 · 暗色 · 字号：设置里点选立即生效；论文正文不受字号影响。
  • English：设置里切换，整个界面变英文，翻译相关的入口一并收起。
  • 全文翻译：整篇译成第二份 PDF，服务在设置里选（默认 bing，免费）。
  • 截图：工具条「截图」或按 c——拖拽框选一块区域，原图直接进剪贴板；设置里可开关是否落盘，文件在截图目录（命名含时间、论文名、页码）。
  • 快捷键：论文界面按 ? 呼出快捷键卡（a 析读 · m AI 眉批 · Ctrl+F 查找 · PageUp/PageDown 翻页）。
  • 节日换装：到日子蛋自己换上——元旦/春节/元宵/妇女节·教师节/植树节/读书日/劳动节/毕业季/儿童节/端午/七夕（2·14 同款）/中秋/万圣/圣诞，立冬到立春戴围巾；清明、国庆等庄重与国家的日子不换。
  • 演示模式：没配模型时顶栏常驻「演示模式」徽标——那时看到的是演示数据，点徽标直达设置配好即走真模型。
  • 蛋：顶栏和书桌各一只，可以戳。PDF 精准丢在蛋上会被它吃掉——吃只是仪式，导入照常。

文献、术语、批注全部保存在本机，在文库可随文献删除，卸载更新重装不会删除。

eggpaper 使用指南

不配模型是「演示模式」；配置方法见设置里的模型教程。

阅读

  • 打开文献：PDF 拖进窗口任意位置（可一次多篇）；或点「论文，启动！」选文件。装好后右键 PDF 可选用 eggpaper 打开。
  • 翻页与缩放：PageUp / PageDown 翻页；缩放条有适宽 / 适页 / 实际大小与百分比，页码可直达；Ctrl + 滚轮只缩论文，锚在光标底下那行。
  • 位置记忆：刷新、重开、换篇，回到你离开的那一行。
  • 查找：Ctrl + F，命中逐处高亮、逐个跳转；范围跟着版面走——原文查原文、译文查译文、双语两边都查。
  • 原文链接：论文里的 DOI 与 arXiv 编号可点，直达 doi.org / arxiv.org。
  • 截图：工具条「截图」或按 c，拖拽框选，原图进剪贴板；设置里可开关「保存到本地」。
  • 划词：选中文字弹出气泡——翻译 / 钉在页边 / 写批注 / 收进术语表 / 提问。
  • 返回原位：Alt + ← 回到跳转前的位置。
  • 快捷键卡：按 ? 唤出常用键（j / k 段间步进、t 译当前段、s 译划选、r 框选、x 收起右栏、a 析读、1 / 2 / 3 换版面）。

顶栏

  • 版面：原文 / 译文 / 双语；双语再分对开（左英右中成对滚动）与交替（一页原文一页译文）。
  • 全文翻译：点「全文翻译」开始，首次自动下载翻译引擎；服务默认 bing（免费），可在设置里换成 openai / google / deepl（DeepL 填 Key）。扫描件（整页位图的老论文）自动按 OCR 排版译——译文黑字、段底铺白，不叠成重影。点「重新全文翻译」强制整篇重译（换服务 / 改术语表后用它）；升级前的扫描件旧译文，第一次点会自动重译一遍。
  • 停止与续传：析读、全文翻译都能中途停止——已生成的部分保留，已译好的页续译接着用。
  • 框选：框选公式 / 图表 / 表格直接提问（需模型支持视觉）；答完钉在你圈的位置。
  • 引用：顶栏「引用」识别一次刊头页脚，本地排十种格式（GB/T 7714 / APA 7 / Nature 体 / 作者 + 年 / 作者 + 期刊 + 年 / 正文括注 / BibTeX / RIS / DOI / 预印本编号），点整行复制。

页边

  • 钉在页边：查译 / 选区问答 / 批注成为页边一张卡，跟随论文保存。
  • 引文：点引文跳回纸上那句话；点「全句」把预览摊开。

右栏

  • 问题：预置七问，综述自动换口径；答案里的 ¶n 代表段落，点击跳回原文（译文 / 双语版面里也会落在对应位置）。
  • 速览：一眼卡、图表速览（点开灯箱放大：在原文查看 / 复制 / 下载 / 问这张图）、方法卡（研究型）或谱系卡（综述）、库内互引（谁引了这篇、哪句、什么立场）；可导出 .md。
  • 提问：多会话；回答逐字流式，可停止生成 / 重新生成 / 删除；被输出上限截断会标出来并给「继续生成」，接着写、写回同一条；空态给三个推荐问题；输入框按 / 勾选其他论文一起问（最多 8 篇，超过 4 篇自动逐篇取材）。引用了别篇时，输入框旁多一枚「数据对比」。
  • 术语：本篇缩写与术语表，划词可收进、可手动加，导出 CSV；下面是跨篇复用的「学科库」——常用译法收一处，本篇优先。

左栏

  • 文库：搜索标题与全文，四种排序；标题双击可改。多选：同屏阅读（2–4 篇）/ 数据对比（2–12 篇）/ 引用导出 CSV / 分类 / 删除。同篇另一版本导入会问一次替换还是保留；导入时按 DOI 补元数据，认不出的留空。
  • 数据对比：标准六维一键开比，或自定义列（列名 + 一句说明）；格子带 ¶ 锚点，可复制 Markdown / 下载 CSV。
  • 从 Zotero 导入：文库底部长按拖放区（需要 Zotero 7 在本机打开）勾选条目，导入 PDF 与相应信息。
  • 论文日历：g c。哪天读了 / 新增了哪篇；点某天 ＋ 列为当日待读，打开即移出；可导出本月 .md。
  • 目录：左侧栏目录按钮（g o），论文自带书签，点击跳页。

设置

  • 护眼底纹：纯白 / 豆沙绿 / 浅青绿 / 米黄，点一下立刻换；另有暗色。
  • 字号：小 / 标准 / 大 / 特大，立刻生效；论文正文不受影响。
  • 图层：页边批注的显示开关。
  • 语言：切英文后翻译相关入口（译文 / 双语 / 术语页签 / t·s 键）收起；已析读内容不变，新生成的走英文。
  • 数据目录：可迁移、可打开查看；卸载与更新都不会删个人数据。
  • 析读：导入后自动开始；关掉只入库、不花 token。段落切分升级后打开旧论文会自动重排段落；旧骨架对不上的那一篇会重析读一遍（花一次模型钱）。
  • 翻译引擎：未装时点「全文翻译」会自动下载；设置里可检测 / 安装 / 升级。
  • 双语：译完在文献文件夹里生成并排双语 PDF（`（双语）.pdf`，每页左原文右译文），可开关。
  • 更新：打开时自动检查；新版断点续传、校验后静默升级。
  • 备份：导出全库 zip / 从备份恢复（恢复在重启后生效）。
  • 截图：可开关「保存到本地」；「打开目录」直达截图文件夹。
  • 窗口：设置里或托盘右键开独立窗口（软件单实例，重复打开只唤起界面）。
  • 演示模式：没配模型时顶栏常驻「演示模式」。

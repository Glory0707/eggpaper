eggpaper 使用指南

不配模型只有演示模式，点设置的教程配。

阅读

  • 打开文献：PDF 拖进窗口任意位置导入（可一次多篇）；或点「论文，启动！」/ 下方印章选文件。装好后右键 PDF 可选用 eggpaper 打开。
  • 翻页与缩放：Ctrl + 滚轮自由缩放。
  • 查找：Ctrl + F，命中高亮；范围跟着版面走（原文 / 译文 / 双语各自查）。
  • 原文链接：论文里的 DOI 与 arXiv 编号可点，直达 doi.org / arxiv.org。
  • 截图：工具条「截图」或按 c，拖拽框选区域，原图进剪贴板；设置里可开关落盘。
  • 划词：选中文字弹出气泡——翻译 / 钉在页边 / 写批注 / 收进术语 / 提问。
  • 回原位：Alt + ← 回到跳转前的位置。

顶栏

全文翻译：原文 · 译文 · 双语三种版面。点「全文翻译」开始（首次自动下载翻译引擎）；服务默认 bing（免费），可在设置换。

停止与续传：析读、全文翻译都能中途停止——已生成的部分保留，已译好的页续译接着用。

框选：框选公式/图表/表格直接提问（需模型支持视觉）。

引用：顶栏「引用」识别后生成各格式，点击复制（GB/T / APA / Nature / BibTeX / RIS / DOI 等）。

页边

  • 钉在页边：查/译/批注成为页边一张卡。

右栏

  • 问题：预置七问，综述自动换口径；答案里的 ¶n 代表段落，点击跳到原文。
  • 速览：一眼卡、图表速览、方法卡（研究型）或谱系卡（综述）、库内互引（谁引了这篇、哪句、什么立场）；可导出 .md，¶n 跳回原文。
  • 提问：多会话，可停止 / 重生成 / 删单条；输入框按 / 勾选其他论文一起问（整个文库也行）。
  • 术语：本篇缩写与术语表，划词可收进、可手动加；可导出 CSV。下面是跨篇复用的「学科库」——常用译法收一处，本篇优先。

左栏

  • 文库：搜索标题与全文，四种排序；标题双击可改。多选：同屏阅读（≤4 篇）/ 数据对比（≤12 篇）/ 引用导出 / 分类 / 删除。同篇另一版本导入会问一次替换还是保留。导入时按 DOI 补元数据，认不出的留空。
  • 从 Zotero 导入：文库底部长按拖放区（需要 Zotero 7 在本机打开）勾选条目，导入PDF和相应信息。
  • 论文日历：g c。哪天读了/新增了哪篇；点某天 ＋ 列为当日待读，打开即移出；可导出本月 .md。
  • 目录：左侧栏目录按钮（g o），论文自带书签，点击跳页。

设置

  • 底纹 · 字号：论文正文不受字号影响。
  • English：切英文后翻译入口收起；已析读内容不变，新生成的走英文。
  • 数据目录：可迁移、可打开查看；卸载与更新都不会删个人数据。
  • 析读：导入后自动开始；关掉只入库、不花 token。
  • 备份：导出全库 zip / 从备份恢复（恢复在重启后生效）。
  • 快捷键：论文界面按 ? 呼出快捷键卡。
  • 独立窗口：设置里或托盘右键打开（软件单实例，重复打开只唤起界面）。
  • 演示模式：没配模型时顶栏常驻「演示模式」。

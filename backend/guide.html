eggpaper 使用指南

读

  • 打开文献：把 PDF 拖进窗口，或点空屏任意位置选择文件；装好 eggpaper 后右键 PDF 可选用 eggpaper 打开
  • 翻页与缩放：底部工具条可翻页、输页码直达、适宽/适页缩放；按住 Ctrl + 滚轮可以自由缩放论文。「适宽」是最常用的档位。
  • 查找：在论文内查找，命中高亮，可逐个跳。
  • 翻译：原文 · 译文 · 双语。译文要先用「整本翻译」生成；双语对开时左右两页同高对齐。
  • 略读：不用细读的段落整段变灰，悬停可看，点灰字变黑（再点撤销）。综述只灰参考文献。
  • 回原位：跳走之后一键回到跳转前的位置。

页边

  • 划词：选中文字弹出气泡——翻译 / 钉在页边 / 写批注 / 收进术语 / 提问。译文页的中文同样可以划选复制。
  • 钉在页边：查译成为页边一张卡，卡片上 × 移除。
  • AI 眉批：右栏「问题」页点「AI 眉批」，模型通读全文后把值得当心/点睛/可疑的句子写在页边。设置里可以关闭。
  • 框选问图：框选公式/图表/表格直接问。

右栏

  • 问题：六个问题：要解决什么 / 为什么 / 怎么解决（综述问「它把文献怎么组织的」）/ 还有什么没解决 / 还能做什么 / 换个学科。¶n 代表段落，点击 ¶n 可跳转到相应原文。
  • 速览：总结、图表速览、方法卡（研究型）或谱系卡（综述）、导师三问、导出 Markdown。
  • 提问：对话式问答，可多会话、可停止/重生成/删除单条。
  • 术语：本篇论文的缩写和术语表，划词可收进；可导出 CSV。

其它

  • 引用：顶栏「引用」——GB/T / APA / Nature / BibTeX / RIS，点击复制。
  • 文库：分类、搜索、增删、按最近阅读排序。
  • 护眼底纹与字号：设置里保存后生效；论文正文不受字号影响。
  • 整本翻译：整篇译成第二份 PDF，服务在设置里选（默认 bing，免费）。
  • 快捷键：论文界面里按 ? 呼出快捷键卡。

文献、术语、批注全部保存在本机，在文库可随文献删除，卸载更新重装不会删除。

配模型

  • 为什么要配：析读、问答、翻译都要调用大模型，没配时是「演示模式」。需要填写BASE URL（接口地址）、API KEY（密钥）、模型名，都只存在本机。费用按用量算，读一篇论文的析读通常几分钱。
  • 以 DeepSeek 为例：
    ① 打开 platform.deepseek.com 注册，充值任意金额；
    ② 左侧「API keys」→「创建 API key」，复制那串 sk-…（只显示这一次）；
    ③ 回 eggpaper 设置：BASE URL 填 https://api.deepseek.com、API KEY 粘贴、模型填 deepseek-flash，点「测试连接」见 ✓ 即可，勾选视觉。
  • 其他：
    • 智谱 GLM（有免费模型，效果有限）：open.bigmodel.cn 注册 → 控制台「API 密钥」创建。BASE URL 填 https://open.bigmodel.cn/api/paas/v4，模型填 glm-4.7-flash（免费）或 glm-4.7 等。
    • 硅基流动（聚合平台，有一批免费模型）：cloud.siliconflow.cn 注册 →「API 密钥」新建。BASE URL 填 https://api.siliconflow.cn/v1，模型在「模型广场」里选。
    • 阿里云百炼（通义千问，新用户有免费额度）：bailian.console.aliyun.com 开通 →「API-KEY 管理」创建。BASE URL 填 https://dashscope.aliyuncs.com/compatible-mode/v1。
    • 任意包含 OpenAI 接口的模型厂商均可使用，BASE URL 需填写 OpenAI Chat/Completions 接口。
  • 填完点「测试连接」；不通多半是模型名或 key 抄错（模型名一律按厂商给的填）。API KEY 等同钱包钥匙，只填在这里，切勿发给别人。

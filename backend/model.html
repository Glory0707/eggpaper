配模型

  • 为什么要配：析读、问答、划词与段落翻译走模型；全文翻译的服务另选（默认 bing，免费不吃 key）。没配时是「演示模式」。
  • 填三样：BASE URL（接口地址）、API KEY（密钥）、模型（模型 id）。都只存在本机，费用按用量算，读一篇论文的析读通常毛钱级。
  • 视觉：勾上＝同一个模型兼做读图（框选问答用）；不勾则框选问答不可用。
  • 以 DeepSeek 为例：
    ① 打开 platform.deepseek.com 注册，充值任意金额；
    ② 左侧「API keys」→「创建 API key」，复制那串 sk-…（只显示这一次）；
    ③ 回 eggpaper 设置：BASE URL 填 https://api.deepseek.com、API KEY 粘贴、模型填 deepseek-flash，勾选视觉，点「测试连接」出 ✓ 即可。
  • 其他：
    • 智谱 GLM（有免费模型，效果有限）：open.bigmodel.cn 注册 → 控制台「API 密钥」创建。BASE URL 填 https://open.bigmodel.cn/api/paas/v4，模型填 glm-4.7-flash（免费）或 glm-4.7 等。
    • 硅基流动（聚合平台，有一批免费模型）：cloud.siliconflow.cn 注册 →「API 密钥」新建。BASE URL 填 https://api.siliconflow.cn/v1，模型在「模型广场」里选。
    • 阿里云百炼（通义千问，新用户有免费额度）：bailian.console.aliyun.com 开通 →「API-KEY 管理」创建。BASE URL 填 https://dashscope.aliyuncs.com/compatible-mode/v1。
    • 本地 Ollama：BASE URL 填 http://localhost:11434/v1，模型填本地拉下来的名字。
    • 其他 OpenAI 兼容端点同理：BASE URL 填到 /v1 为止，不要带 /chat/completions。
  • 不通多半是模型名或 key 抄错（模型名一律按厂商给的填）。API KEY 等同钱包钥匙，只填在这里，切勿发给别人。

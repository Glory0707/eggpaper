配模型 eggpaper

  • 为什么要配：析读、问答、翻译都要调一个大模型，没配时是「演示模式」（数据是假的）。要填的只有三样——BASE URL（接口地址）、API KEY（密钥）、模型名，都只存在本机。费用按用量算，读一篇论文的析读通常几分钱。
  • 三步上手（以 DeepSeek 为例）： ① 打开 platform.deepseek.com 注册，充 10 元（能用很久）； ② 左侧「API keys」→「创建 API key」，复制那串 sk-…（只显示这一次）； ③ 回 eggpaper 设置：BASE URL 填 https://api.deepseek.com、API KEY 粘贴、模型填 deepseek-flash，点「测试连接」见 ✓ 即成。
  • 其他家（同样三样，照抄即可）：
    • 智谱 GLM（有免费模型，可先零成本试用）：open.bigmodel.cn 注册 → 控制台「API 密钥」创建。BASE URL 填 https://open.bigmodel.cn/api/paas/v4，模型填 glm-4.7-flash（免费）或 glm-4.7 等。
    • 硅基流动（聚合平台，有一批免费小模型）：cloud.siliconflow.cn 注册 →「API 密钥」新建。BASE URL 填 https://api.siliconflow.cn/v1，模型在「模型广场」里挑，名字照抄（标「免费」的也能用）。
    • 阿里云百炼（通义千问，新人有免费额度）：bailian.console.aliyun.com 开通 →「API-KEY 管理」创建。BASE URL 填 https://dashscope.aliyuncs.com/compatible-mode/v1，模型填 qwen-plus 等。
  • 零成本离线：装好 Ollama 并拉一个模型后，BASE URL 填 http://127.0.0.1:11434/v1，模型填它的名字（如 qwen3:8b）——数据不出本机。
  • 填完点「测试连接」当场验真；不通多半是模型名抄错或 key 少了字符。API KEY 等同钱包钥匙，只填在这里，别发给别人。

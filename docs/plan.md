### T4 功能走查（每功能实测顺手度）

走查协议：每项功能按脚本操作，记录 完成秒数 / 卡点 / 情绪；卡点修复或砍功能，不修说明理由。

| 问答 | 问固定 3 问 → 点引用跳转 | 引用跳转准确 |
| 删除 | 删一篇 → 文库与视图正确清空 | 无残留 |

## M3.4 · 体感修整（用户五条反馈）✅ 已完成（2026-09-11）

用户原话逐条落地，验收全部走浏览器实测（1600×1000 与 1280×760 两档窗口）：

| # | 反馈 | 处理 | 实测证据 |
|---|---|---|---|
| 1 | logo 还是像水滴，因为上面是尖的 | 蛋形重画：上下两个半椭圆在最宽处相切（上半径 40 < 下半径 52），钝端朝上、尖端朝下；裂缝改斜向从左腰爬到右上壳沿 | 16/25/60/116/190/340px 六档目检，蛋形稳定可辨；favicon 用简版（16px 下裂缝糊成一团） |
| 2 | 字体太杂乱，别用楷体，要饱满、要统一 | 四声字体砍成两声 + 一个署名：删掉 `--kai`（楷体在 Windows 太细太干瘪），全部人声文本归 Inter/雅黑；Fraunces 只留 wordmark | CDP `CSS.getPlatformFontsForNode` 验证：中文全部 Microsoft YaHei UI，拉丁 Inter，无楷体残留 |
| 3 | 旁批的 1/2/3 不知何用、点了没反应、会闪退、长批注展开压住下一条 | 书签改成**角色首字**（背/缺/主/证/对/流/拓/限）；角色卡改为 fixed 定位、**只由点击开关**（原 hover 卡与被 hover 的标签之间有 10px 死区，鼠标一离开就卸载，所以永远点不到 = "闪退"）；卡上写明出处与改判入口 | 角色卡四条开关路径全过：Esc ✓ 点外 ✓ 同书签再点 ✓ 悬停不弹 ✓ |
| 4 | 长批注展开覆盖下一条 | 高度不再估算，改为**渲染后实测再摆第二遍**；展开时下方批注整体下让，页边随之变长；正文卡内滚动 ≤240px | 逐页把所有可展开批注展开：overlap=0 spill=0，页边 818→974 长出来消化掉 |
| 5 | 右侧分工不明，本文缩写该进术语 | 本文缩写从「速览」移到「术语」并圈进 200px 滚动区（21 条缩写不再把术语表顶到屏幕外）；骨架页签补角色图例（首字+全称+条数，点击跳该角色首段） | 术语表表单 y=360，无需滚动即可见 |
| 6 | 框选后想取消找不到按钮 | 框选模式加**顶部常驻提示条**（框选 / 说明 / Esc / 退出按钮）；选区气泡的 × **常显**（原先只在出答案后才出现）；Esc 一键退出；点浮层外关闭 | hint=1 exitBtn=1；visClose 常显 ✓；Esc 后 frame 按钮熄灭 ✓ |

顺带修掉三处旧疾：
- 页边批注原来只有「查译」能给删，自动眉批删不掉 → 所有批注都可 ×，后端本来就支持
- 框选答疑钉页边时写死 `para_idx:0,page:0`，永远落在第一页第一段 → 改为记录框选所在的页/段/PDF 坐标矩形；同段落多个区域答疑不再互相覆盖（`/pin` 带 rect 时不参与按段去重）
- 三态/对开/缩放的**选择只在滚动时才存**，刷新后经常回到上一个模式 → 换姿势即存

浮层定位统一走书桌中线（`.desk-float` 用 `translate` 而非 `transform`，这样 `pop` 动画不会把居中偏移冲掉）；缩放条、返回原位、框选提示条三件浮层现在都正对书桌，不再偏到右栏底下。

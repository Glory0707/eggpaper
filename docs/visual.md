# eggpaper 视觉与动效规范

> v0.1 · 2026-09-11。上位：[design.md](design.md)（语言：灯下批注本）、[ux.md](ux.md)（交互逻辑）。本文把"美观度、设计感、丝滑度"落成可直接实现的 token 与清单。

---

## 1. 字体：四种声音，各说各话

排版的核心思想：**每个字体家族只有一种职责**，用户不需要读懂文字就知道这块内容是什么性质。工作声必须用现代工具软件的通行选择（Inter）——个性留给品牌与眉批，界面才不僵硬。

| 声音 | 家族 | 只用于 | 字号/行高 |
|---|---|---|---|
| 工作声（sans） | Inter Variable + 微软雅黑 | 全部 UI 控件 + 全部内容文本（骨架树、一眼卡、问答正文、摘要） | 13–14.5px / 1.6–1.7 |
| 标签声（mono） | JetBrains Mono | 小节标签（大写+0.13em 字距）、¶号、状态点、元信息 | 9–10.5px |
| 人声（kai） | LXGW WenKai / 楷体 | 眉批、查译、目的批注——"有人在对你说" | 13px / 1.5 |
| 品牌声（serif italic） | Fraunces italic | 仅 wordmark | 21px |

**字号阶梯**（基础 13，不做中间值）：display 21（仅 wordmark）→ title 14.5 → h 14 → body 13.5 → ui 13 → small 12 → micro 10.5。一屏内字号种类 ≤4。

**位置规则**：标签一律在内容上方，不放旁边（减少横向扫视）；右栏内容左对齐、行长 ≤34em（中文阅读最佳）；间距走 4px 网格（4/8/12/16/24）；标题类字距 -0.01em，¶号与页数用 `font-variant-numeric: tabular-nums`。

## 2. 配色：灯下的纸

分层逻辑——**越靠近内容越亮，四周越暖暗**（台灯打在书页上的光感）：

```
桌面 --paper     #EFE8D8   （最暗，最远）
内嵌 --paper-deep #E6DCC6   （左栏、沟槽底）
面板 --card      #FAF6EA
浮层 --card-2    #FFFDF6   （最亮：阅读内容、气泡、弹窗）
```

- **墨色只许三级**：ink `#262015`（正文）/ ink-2 `#57503F`（次级）/ ink-3 `#8D8066`（micro 标签专用）。禁纯黑；正文对比度 ≥7:1。
- **蛋黄是唯一的强调色**：主按钮、当前态、高亮底。禁止大面积铺。
- **八角色色只是调味**：只以 ≤14px 书签片、3px 竖条、≤18% 透明度高亮出现，永不作填充色。
- **阴影 = 悬浮 = 暂时的**。静态布局只用发丝线+留白分隔；shadow 只给 popover/modal/拖拽悬停这类"临时浮起"的东西。这条是"设计感"的最高纪律。

## 3. 小元素巧思（全部服务"批注本"隐喻，克制执行）

1. **书签片**：角色标签保持金属内嵌阴影，hover 滑出 2px 带投影——像把书签从书页里抽出来。
2. **眉批引线**：引文高亮与页边批注之间画一条同色**点状引导线**（古书脚注的引线），代替生硬的相邻摆放。
3. **略读蒙纱 = 一层薄纸**：半透明纸色 + 段落边缘 1px mask 渐隐，像盖了张描图纸，而不是"禁用置灰"。
4. **析读进度 = 笔画下划线**：不用进度条，一根发丝琥珀线像下划线一样自己画过去，旁边衬线数字"通读 ¶13/23"逐字走。
5. **拖入鸡蛋裂开**：空状态拖拽悬停时，线稿蛋壳出现一道细裂纹——剥壳隐喻，仅在 dragover 态。
6. **Analysis 完成蛋黄一颤**：wordmark 蛋黄 400ms 内 2° 摆动一次，只在析读完成瞬间。彩蛋级，别处不用。
7. **highlight 描画**：眉批引文高亮以 scaleX 0→1 从左向右"画"出来（300ms），像被人拿笔当场划的。

其余一律不加装饰——巧思的价值在密度控制：**一屏最多一个惊喜**。

## 4. 动效：macOS 式丝滑的纪律

丝滑不是动画多，是**短、少、有物理感、零跳变**。

### 缓动与时长 token

```css
--ease-out:   cubic-bezier(.25, 1, .3, 1);      /* 出场：淡入+上浮 8px */
--ease-spring:cubic-bezier(.34, 1.4, .44, 1);   /* 轻弹性：气泡、toast */
--ease-smooth:cubic-bezier(.4, 0, .2, 1);       /* 通用状态：颜色/边框 */
--t-fast: 120ms;   /* hover、颜色 */
--t-base: 200ms;   /* 气泡、popover */
--t-slow: 320ms;   /* 栏折叠、抽屉 */
```
一切过渡 ≤320ms；退场永远比入场短（120ms 纯淡出，无回弹）。

### 动效清单（全量，此外不加）

| 场景 | 动效 |
|---|---|
| 按钮/标签 hover | translateY(-1px)+浅影，120ms ease-out（已有，保留） |
| 气泡/角色卡入场 | opacity+translateY(4px)+scale(.98→1)，200ms spring；退场 120ms 淡出 |
| 略读开关 | 蒙纱按段落顺序 **stagger 波浪展开**，每段延迟 12ms（总长≤400ms）——"系统感"的点睛 |
| 眉批生成完成 | 批注卡 stagger 入场（60ms 间隔），引文高亮做描画（见 3.7） |
| 右栏折叠/文库浮出 | 宽度 320ms smooth + 内容 120ms 淡入；浮出面板带 40% 遮罩淡入 |
| 三态翻译切换 | 旧内容 120ms 墨色淡出 → 新页渲染 → 150ms 淡入。**不做翻页动画**（噱头） |
| 位置恢复 | **瞬时，无动画**——恢复是功能不是表演 |
| 骨架跳转 | smooth scroll（已有）+ 目标琥珀描边 1.6s 渐隐（已有） |
| toast | 底部上浮 8px+淡入 200ms spring，单实例 |
| 全局 | `prefers-reduced-motion: reduce` 时全部动效关闭 |

### 性能纪律

只动 `opacity` / `transform`；滚动跟随用 IntersectionObserver 不挂 scroll handler；canvas 重渲染去抖 160ms；`will-change` 只加在已知将动的浮层上。

## 5. 验收方式

M2.6 完成后录屏对照检查：a) 一屏内字体家族 ≤3、字号 ≤4；b) 静态区域无阴影；c) 所有交互动效 ≤320ms 且缓动来自 token；d) `prefers-reduced-motion` 下无动画；e) 60fps 目检（略读波浪、栏折叠、气泡）。
